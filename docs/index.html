How the pipeline works

Three stages, one output folder. Collection can take one to three hours; analyze and report are seconds to a minute.

Why portal tokens?

Many tenants block admin consent for Microsoft Graph Command Line Tools. This tool attaches to Edge/Brave/Chrome (or reuses az / Graph PowerShell) and uses already-consented first-party portal apps. Advanced Hunting prefers the Defender portal apiproxy when Graph hunting scopes are missing.

What it collects

Artifacts land in output_YYYY-MM-DD_HHMM/. Collection is adaptive: Defender tables are probed first; missing Device* means RMM/TVM are not assessed, not clean.

Identity & CA

  • Conditional Access + named locations
  • MFA registration, guests, inactive users
  • Risk users / detections
  • Device code, legacy, failed sign-in digests

Privilege & apps

  • GA / hybrid / privileged hygiene
  • Path-to-GA Graph permissions
  • Live SPN sign-ins vs dormant grants
  • Secrets, wildcards, consent surface

Defender / M365

  • Schema discovery (19_Hunting_Schema)
  • RMM, TVM, GenAI, file-share (when tables exist)
  • Alerts, Exposure Graph, IdentityInfo
  • Mail / Teams / cross-tenant samples

Secure Score

  • Live in-scope controls by category
  • Not the inflated 400+ profile catalog
  • Separate from expert posture score
Failed Graph steps (403) are recorded in the manifest and shown under Limitations. A missing SharePoint settings call is not a clean bill of health.

Expert analyzer

lib/analyze.js is a deterministic expert system — correlation rules over CSVs, not a live LLM. It emits NARR.* narratives with severity, priority (Now / Next / Later), evidence, and remediation, plus a posture score 0–100.

IdeaExample
Config ∩ activity Dangerous Graph grant and active SPN sign-ins → harden now; never-seen grant → delete candidate
Context-aware severity Large MFA registration inventory becomes Medium when enforced MFA CA already exists
Office noise vs spray Failed logon bursts often map to site egress / shared mailboxes — confirm IPs with IT
First-party filter Microsoft 365 Backup Directory write is not framed as third-party vendor sprawl 
node analyze.js output_YYYY-MM-DD_HHMM
# writes 00_Expert_Findings.csv / .json

HTML report & Excel

A successful collect already writes the reports. report.js rebuilds 00_REPORT.html and 00_Remediation_Plan.xlsx (and re-runs the analyzer). Use the in-page Export Excel / Download PDF buttons as needed.

Quick start

npm install

# Preview what this session can collect
node collect.js --check-permissions --auth browser --cdp http://127.0.0.1:9222

# Full run
node collect.js --auth browser --cdp http://127.0.0.1:9222 \
  --tenant <customer-tenant-guid> \
  --inactive-days 90 --device-stale-months 3 --signin-days 30,90

# Resume failed steps only
node collect.js --resume output_YYYY-MM-DD_HHMM

# Report
node report.js output_YYYY-MM-DD_HHMM
